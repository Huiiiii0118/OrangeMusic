# 橙子音乐 · iOS 测试版

测试版是**本地运行的正式版镜像**：直接服务 `ios/www`（正式版构建产物），服务脚本与云端部署完全同构（`www/server.js`：静态站点 + `/api/*` 音源接口）。

## 启动

- 双击 `启动测试版.cmd`，或
- 命令行：`node test/start.mjs`（默认端口 3000，可用 `PORT=3001` 换端口）

访问：

- 电脑浏览器：`http://localhost:3000`（构建产物写死 iOS 界面，电脑上也能完整测试 iOS UI）
- 手机（同一 Wi-Fi）：`http://<本机IP>:3000`
- 本地测试环境自动以「本地测试」账号登录，数据只存本机，不碰云端账号。

## 测试注意

- 改代码后重新构建（`node tools/build_web.js --out www --platform ios`），**刷新页面即可生效**，无需重启服务（服务实时读 www 目录）。
- 偶发页面异常时强刷（或清 Service Worker）再看。

## iOS 端更新工作流（2026-11-15 起生效）

1. **改代码**（`ios/shared/...`）。
2. **本地测试版更新测试**：构建到 `ios/www`，经 `ios/test` 入口启动本地服务验证（本目录）。
3. **用户确认**测试版是否符合要求。
4. **经确认后**迭代版本号 `vX.Y.Z`（只改 iOS 端，与 Windows 版本互相独立），撰写本次更新说明存放 `ios/RELEASE_NOTES/vX.Y.Z.md`（首行 `# vX.Y.Z（YYYY-MM-DD）`）。
5. **更新说明与版本号再次确认**后：
   - 推送更新说明到云端 —— 云端（`release-notes.json`）只保留**最近 3 次**更新说明（构建时按版本倒序截取，多出的最旧版本不进产物；`ios/RELEASE_NOTES/` 目录历史文件留档不删）；
   - 并把最新代码推送到云端，更新正式版软件。
6. **正式版落地后**，测试版即与云端正式版同步（同一份 `ios/www`），作为下次测试的基线。
