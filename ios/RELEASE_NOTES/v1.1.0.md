# v1.1.0（2026-11-16）

界面与播放体验的一轮打磨：全屏显示、更舒服的歌词排版、更聪明的搜索，以及随机模式下「上一首」终于回到你听过的上一首。

## 显示

- 顶部间距统一：所有页面顶部留出一致的呼吸间距，灵动岛 / 刘海机型不会挡住标题，也不会出现大片空白。
- 全屏显示：Safari「添加到主屏幕」后铺满整屏，状态栏与页面同色，顶部不再留黑边。

## 播放

- 随机模式的「上一首」现在回到上一首播放过的歌，而不是随机跳。
- 播放页「喜欢」按钮改为实心爱心，文案固定为「喜欢」。
- 播放列表右上角「更多」点开菜单：播放相似单曲 / 我喜欢 / 添加到 / 移动到 / 删除。
- 「更多」面板里的播放模式与「添加到 / 定时 / 音质 / 倍速」并列成一排同款按钮。
- 去掉播放页与底部播放条上的进度显示，界面更干净。

## 歌词

- 行距与字距放宽，长句折行不再黏在一起，整屏读起来更轻松。
- 拖动歌词不再改变播放进度，歌词页只用于浏览。

## 搜索

- 新增一路音源聚合，正式发行版不再被过滤掉，搜歌手名的结果更全更准。

## 设置

- 设置页拆成「设置 / 关于」两个卡片。
- 「关于」里可查看最近 3 次更新说明。
