# v1.0.0（2026-11-15）

首个 iOS 正式版。橙子音乐是一款无广告、不追踪的跨平台音乐播放器，iOS 端以网页 / PWA 形式提供，可用 Safari 打开后「添加到主屏幕」像原生应用一样使用。

## 本版功能

- 海量曲库：聚合多家音源，按「歌名 + 歌手」搜索，自动择优取链。
- 真实榜单：QQ 音乐、网易云等榜单真实曲目，按板块智能归并。
- 发现 / 推荐：歌单广场、热门歌手、口味推荐、电台。
- 歌词：多通道竞速匹配 LRC 歌词，全屏同步歌词。
- 播放体验：播放队列、播放模式、音量律动可视化、锁屏 / 控制中心媒体控制。
- 账号与同步：登录后跨设备同步收藏、歌单、播放进度。
- 隐私优先：不上报任何行为数据，不接入广告与统计 SDK。
